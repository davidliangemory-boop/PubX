===== BEGIN FULL PRODUCT SPEC (VERBATIM) =====
把事件详情页改造成“研究文章式页面”。后台可以保留结构化字段，但前台只展示有内容、有判断价值的部分。
一、先修数据逻辑，再改UI
当前最大的底层问题不是字段少，而是没有真正形成“事件资料包”。
每个事件应自动收集四类材料：
| 材料层级 | 内容                   | 用途             |
| ---- | -------------------- | -------------- |
| 核心文件 | 初始公告、正式协议、通函、完成/终止公告 | 确认交易事实和条款      |
| 进展文件 | 补充公告、审批进展、表决结果       | 更新事件状态         |
| 企业资料 | 年报、半年报、投资者演示         | 分析经营、财务和战略背景   |
| 外部资料 | 新闻、券商研报、行业报告         | 提供市场观点、类案和行业基准 |
例如国泰君安国际事件，必须先把8月7日初始公告、8月28日时间表更新、9月28日月度更新、10月16日审批进展、2026年半年报合并起来，再生成详情页。
规则22每日交易披露只能作为事件附件，不能成为独立事件，也不能干扰“最新实质进展”。
二、事件页改成六个区域
| 区域         | 展示内容                       | UI规则        |
| ---------- | -------------------------- | ----------- |
| 事件标题       | 主体＋动作＋最新进展                 | 不直接复制公告长标题  |
| 一屏摘要       | 300—500字说明发生了什么、进展到哪、为什么重要 | 默认完整展示      |
| 核心数字       | 金额、价格、溢价、估值、持股、关键日期        | 最多6项        |
| 类案对比       | 2—3个最相关案例及差异               | 必须解释差异意味着什么 |
| 行业对比       | 估值、经营、行业趋势和市场位置            | 明确样本和日期     |
| 财务/战略/投资意义 | 基于上述事实形成判断                 | 每项2—4个具体结论  |
页面底部再放：
* 关键时间线；
* 尚待观察事项；
* 原始文件及外部来源。
删除目前的“A—G数据库分区感”，也删除“交易条款十几项全部展开”的设计。
三、首页第一屏应当直接解决问题
以国泰君安国际页面为例，第一屏可以是：
国泰海通拟私有化国泰君安国际
上海市国资程序已完成，国家发改委程序仍待完成
| 注销价   | 预计现金需求           | 估值     | 停牌前溢价 | 当前阶段   |
| ----- | ---------------- | ------ | ----- | ------ |
| 3港元/股 | 98.61亿—126.15亿港元 | 1.8倍PB | 44.2% | 先决条件阶段 |
下方直接用一段话解释：
国泰海通拟通过协议安排私有化国泰君安国际。媒体普遍按剩余少数股权估算对价约75亿港元，但公告显示，考虑借出股份、可交换债及期权后的实施现金需求为约98.61亿港元，最高约126.15亿港元，并由兴业银行外部融资提供资金。10月16日上海市国资程序已经完成，当前主要前置障碍是国家发改委程序。
用户进入页面后，不需要翻阅十几个模块，就能理解交易。
四、空字段处理规则
前台禁止出现：
undisclosed
null
[]
analysis
disclosed
资料不足
未抽取
改为三条规则：
1. 非关键字段为空：不渲染。
2. 关键事实尚未找到：转换成具体待观察问题。
3. 整个模块没有有效内容：整个模块隐藏。
例如不要显示：
融资：undisclosed
而应在“待观察”中写：
兴业银行融资的利率、期限及担保安排尚未公开，暂时无法测算私有化的新增融资成本。
“没有数据”只有在影响结论时才值得展示。
五、类案与行业对比必须分开
类案对比回答“类似动作以前怎么做”
系统按以下优先级选择案例：
1. 同一交易动作；
2. 同一行业；
3. 同一控股结构；
4. 同一市场及监管路径；
5. 相似交易规模；
6. 相似财务状态。
国泰君安国际应优先匹配：
* 海通国际私有化：同集团、同券商行业、同为控股股东私有化；
* 恒生银行私有化：同为金融机构控股股东收购少数股权，且均采用1.8倍PB；
* 必要时再补一个近期港股协议安排私有化案例。
每个类案只比较真正有解释力的内容：
| 比较项    | 本案     | 类案           | 对本案意味着什么        |
| ------ | ------ | ------------ | --------------- |
| 标的经营状态 | 盈利增长   | 海通国际连续亏损     | 本案不是救助式退市       |
| PB     | 1.8倍   | 海通国际约0.61倍   | 本案支付了明显的增长和整合溢价 |
| 资金来源   | 外部银行融资 | 汇丰收购恒生使用自有资金 | 本案更需关注融资成本和资本压力 |
行业对比回答“公司处在行业什么位置”
证券行业至少比较：
* 收入和利润增速；
* ROE；
* PB、PE；
* 杠杆率；
* 经纪、投行、机构业务排名；
* 行业总体成交量和盈利趋势；
* 头部券商境外资本投入及整合趋势。
不同研报的样本不同，必须写明：
港股上市券商全样本PB中位数约0.51倍；头部券商H股样本平均约0.8倍；本次要约为1.8倍。两个行业数字口径不同，但本案估值明显高于两者。
不能只显示一个没有口径的“行业平均”。
六、财务、战略、投资分析固定回答不同问题
| 维度  | 必须回答                   | 禁止生成        |
| --- | ---------------------- | ----------- |
| 财务  | 花多少钱、资金从哪来、对债务和利润有什么影响 | “有利于提升财务表现” |
| 战略  | 解决什么组织或业务问题、控制权变化后能做什么 | “有利于增强协同效应” |
| 投资  | 价格是否合理、完成概率、催化剂、上下行空间  | “投资者应谨慎关注”  |
国泰君安国际的正确分析应是：
* **财务：**原本已经并表，私有化不会直接增加集团收入和资产；主要影响是取得全部经济权益，同时承担约98.61亿至126.15亿港元收购资金及融资成本。
* **战略：**解决国泰君安国际与海通国际的潜在同业竞争，消除两个境外平台之间的治理和利益边界，为统一资本、客户、牌照及风险管理创造条件。
* **投资：**3港元不会提高，股价上行空间被基本锁定；主要变量转为发改委程序、股东及法院批准、完成时间和资金时间价值。标的仍在增长，少数股东获得高溢价退出，但同时放弃整合后的长期收益。
每个判断后都应能点击查看支持它的公告、财务数据、新闻或研报。
七、不要强迫所有事件使用同一深度
建议设置两种页面：
普通事件页
适用于信息较少或重要性较低的事件，只展示：
* 150—300字事实摘要；
* 最新变化；
* 关键数字；
* 原始来源。
重点研究页
满足以下条件后再生成：
* 已找到核心公告或协议；
* 已形成完整事件链；
* 可以找到至少一个有效类案；
* 可以取得行业或企业财务数据；
* 财务、战略、投资至少有两个维度能形成实质分析。
这样可以避免为了维持统一模板而制造大量空白内容。
八、实施顺序
P0：先把页面救回来
* 前端不再渲染空字段和内部状态码；
* 修复事件首次披露日期和文件链；
* 从PDF全文提取，不再只看首页；
* 用研究摘要替代字段矩阵；
* 先人工校准10个重点港股事件。
P1：建立研究能力
* 接入新闻、年报、半年报及研报；
* 建立类案推荐；
* 建立行业指标模板；
* 生成财务、战略、投资三类分析；
* 对“公告金额与媒体金额不一致”等冲突自动解释。
P2：再扩大覆盖
* 将同一逻辑迁移到出海信披和SEC；
* 根据交易类型配置不同分析模板；
* 建立事实更新后自动重写摘要的机制；
* 统计用户点击、停留和来源展开情况，判断哪些内容真正有用。
验收标准
一个重点事件页必须做到：
* 用户30秒内知道发生了什么、进展到哪、规模多大、为什么重要；
* 页面不存在任何null/undisclosed/[]；
* 首次披露、最新进展和关键数字均能回溯到原文；
* 有2—3个真正可比的案例；
* 行业数据注明样本、日期和口径；
* 财务、战略、投资分析均包含具体事实和因果关系；
* 高频程序性公告不会挤占主体内容。
一句话概括：后台继续结构化，前台彻底内容化；用字段支持研究，但绝不能让用户阅读字段。

===== 用户此前对国泰君安国际页面的原始核查与目标页面（同样原文保存到 docs/EVENT_RESEARCH_PAGE.md 附录） =====
页面问题：页面把“首次披露”写成 2026年10月16日，但私有化方案首次联合公告实际发布于 8月7日，交易要求于7月22日提出。目前只挂入10月16日进展公告和一份规则22交易披露，没有把8月7日的40页初始公告、8月28日时间表更新、9月28日月度更新及半年报串进来。因此对价、融资、持股、条件等明明已有公开信息，却被渲染为“未披露”。

目标页面：
国泰海通拟私有化国泰君安国际
当前状态：上海市国资审批已完成，国家发改委程序仍待完成
国泰海通金融控股拟通过香港《公司条例》第673条下的协议安排，以每股3港元现金注销国泰君安国际的计划股份，并撤销其港股上市地位。要约人持有约73.92%的已发行股份；但受8亿股借出股份、可交换债及期权安排影响，计划股份约占34.47%，不能简单按照“26.08%少数股权”计算收购成本。
截至2026年10月16日，上海市国资委及授权单位的批准、审阅和备案已经完成，国家发改委相关程序仍未完成。发改委程序属于提出方案前不可豁免的先决条件；完成后还需寄发计划文件、召开法院会议及股东大会，并取得香港高等法院批准。
核心交易数据：注销价每股3港元现金，价格不会提高，派息可能相应扣减；要约人持股约73.92%（含借出股份）；计划股份约32.85亿股，占已发行股份约34.47%；基础现金需求约98.61亿港元；极端上限约126.15亿港元；资金来源兴业银行外部银行融资；对停牌前收市价溢价44.2%，对应2025年净资产约1.8倍PB；先决条件截止日2026年10月31日；全部条件截止日2026年12月31日。
媒体常见的“约75亿港元”是按照73.92%持股比例简单推算剩余股权所得，没有完整计入借出股份、可交换债和期权情景，产品应直接解释此差异。
经营背景：2026年上半年收入38.71亿港元，同比增长37%；归母利润6.75亿港元，同比增长23%；年化ROE 8.4%；总资产增长41%，负债增长46%，杠杆率由8.74倍升至12.42倍，资本负债率由1.68倍升至2.22倍。不是经营恶化后被救助退市。
类案：海通国际私有化（控股股东原持股73.40%，1.52港元/股，溢价114.08%，较2023年中期NAV折价39.32%约0.61倍PB，现金需求最高约34.70亿港元，2022年亏损65.41亿港元，外部融资，目的为股东支持、解除上市约束）；恒生银行私有化（汇丰已控股，155港元/股，较30日均价溢价33%，1.8倍PB，隐含估值约2,900亿港元，汇丰自有资金，目的为强化香港业务）。
行业：港股上市券商全样本PB中位数约0.51倍、平均约0.52倍（公开报道）；头部券商H股样本平均约0.8倍（券商研报）；SFC数据：香港证券业2025年上半年净利润较此前半年增长14%，交易所参与者净利润增长34%；2025年市场日均成交额同比增长90%。本案更接近“行业景气修复期内的集团整合”。
UI硬规则：顶部只放短标题、当前阶段、最新实质变化、5—7个关键数字；有内容才显示模块；undisclosed/null/analysis/disclosed 永不面向用户展示；来源标签为“公告事实 / 财务数据 / 新闻观点 / 本站分析”，点击查看原文；规则22每日交易披露默认折叠；页面标题用事件名称；“判断与条件方案”改成“下一关键节点”，不生成空泛动作建议。
