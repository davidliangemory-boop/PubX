# 事件研究页改版 brief（David 原文，未压缩）

明白，主分支已恢复到修改前状态；刚才的实施已通过回滚提交撤销。
下面这份可以直接交给你的 agent。
一、统一改版原则
三个 Tab 都从“字段展示页”改成“事件研究页”。
用户进入详情页后，应依次回答：
1. 发生了什么？
2. 现在进行到哪一步？
3. 涉及多少钱、多少股权或多大业务规模？
4. 为什么公司要做？
5. 对财务、战略和投资判断有什么影响？
6. 可以和哪些案例比较？
7. 接下来什么变化会改变结论？
不要再做：
* 展示 null、[]、undisclosed、analysis 等底层值。
* 用“未披露/未抽取”填满页面。
* 为了字段完整而输出空模块。
* 把公告数量增加误判为事件取得新进展。
* 直接把公告标题、附件条款、金额抽取结果原样倾倒给用户。
* 没有可靠类案时硬凑三个案例。
统一详情页结构
建议三个 Tab 共用以下骨架：
1. 事件标题
2. 当前状态及最新实质变化
3. 150—300字事件摘要
4. 3—5个关键数字
5. 财务、战略、投资意义
6. 类案对比
7. 行业对比
8. 会改变判断的关键变量
9. 精简事件时间线
10. 来源与分析边界
缺少内容时，整个模块隐藏，而不是显示“暂无”。
列表页卡片只展示：
* 简化后的事件标题
* 阶段标签
* 一句话摘要
* 最多三个关键数字
* 最新实质变化
* “公告速览/公开资料深读”标签
二、出海信披 Tab
页面定位
重点不是“公司发布了什么公告”，而是：
中国企业在境外买了什么、建了什么、投了多少钱、取得什么权益，项目能否真正落地。
详情页模块
1. 交易本身
首屏必须明确：
* 买方、卖方、标的
* 国家和具体地区
* 交易形式：股权收购、资产收购、合资、绿地投资、包销合作等
* 拟取得权益
* 对价及支付结构
* 当前阶段：意向、正式协议、审批、交割、建设、投产
标题建议采用：
企业＋核心动作＋国家/资产
例如：
龙佰集团拟以1.6亿澳元切入西澳矿砂项目
而不是把公司全称、金额、地区、交易类型全部拼接成一行。
2. 项目成熟度
资源和制造项目建议单独展示：
* 是否取得采矿、建设或经营许可
* 是否完成PFS/BFS
* 是否作出最终投资决定
* 是否已投产
* 资源量、设计产能、预计矿龄
* 后续资本开支
这是判断“购买成熟资产”还是“购买开发期项目”的关键。
3. 公开报道检索
优先级建议：
1. A股公告、巨潮原文
2. 境外交易对手公告、当地交易所文件
3. 东道国监管机构
4. 标的公司年报、可行性研究
5. Reuters、当地财经媒体
6. 政府或行业研究报告
例如龙佰项目不能只写“出资1.6亿澳元取得80%权益”，还应补充项目尚未投产、许可状态、商品价格周期以及FIRB等监管变量。公告显示其中现金约2,000万澳元、设备作价约1.4亿澳元，两个项目尚未获得采矿许可。paper.cnstock.com Image Resources年报同时显示2025年锆英砂、钛铁矿和金红石基准价格均有所下降。FinancialFilings
4. 类案选择
类案排序标准应为：
* 同一国家
* 同一资产类别
* 相同交易结构
* 相近项目阶段
* 相同监管路径
* 中国企业作为买方或产业投资者
不能仅因为都属于“矿业”或“并购”就视为可比。
每个类案只写三项：
* 案例发生了什么
* 与本案哪里相似、哪里不同
* 对本案最有价值的启示
5. 商业意义
财务：
* 当期现金支出与总承诺是否一致
* 是否包含设备、股权或或有付款
* 后续开发资本开支
* 汇率、商品价格、融资成本影响
战略：
* 是否获得资源、产能、渠道或技术
* 是否加强供应链安全
* 是否形成海外生产基地
* 是否与现有主营业务协同
投资：
* 真正的催化点是签约、审批、交割还是投产
* 当前估值是否已经反映交易预期
* 最大失败点及下行情景
* 哪些指标可以验证战略开始兑现
三、港股 Tab
页面定位
重点是把大量公告还原成一个连续事件，而不是让用户阅读文件流水。
首先解决事件链问题
需要区分：
* 首次方案公告
* 补充或条件进展
* 通函
* 独立财务顾问意见
* 股东大会/法院会议结果
* 完成或终止
* Rule 22交易披露等辅助材料
Rule 22证券交易披露通常不应显示成“私有化取得新进展”。列表页的“最新变化”必须取最新一份实质性公告，而不是最新文件日期。
私有化/收购事件详情
建议首屏直接展示：
* 每股要约价或注销价
* 相对停牌前价格的溢价
* 隐含P/B、P/E或EV
* 要约人交易前持股
* 最高现金需求
* 融资来源
* 当前尚未完成的条件
* 预计投票、法院及撤销上市时间
以国泰君安国际为例，用户首先应看到“每股3港元、溢价44.2%、隐含约1.8倍P/B”，而不是先看到十几个字段和公告代码。每经网
港股不同事件类型应使用不同模板
私有化/收购
突出价格、溢价、投票门槛、融资和时间表。
Chapter 14交易
突出百分比率、交易分类、股东批准、对价、标的盈利及估值。
关连交易/CCT
突出关联关系、年度上限、定价机制、独立股东批准和IFA结论。
配售/供股
突出发行规模、折让、摊薄、资金用途和主要股东变化。
监管执法
突出监管机构、具体行为、处罚结果、业务限制及治理影响。
类案对比
港股类案不应只按发行人行业匹配，还应加入：
* 协议安排还是全面要约
* 控股股东私有化还是第三方收购
* 现金还是换股
* 是否为金融机构
* 溢价和估值倍数
* 盈利还是亏损状态
* 融资来源
* 是否有监管或法院条件
建议类案表只保留：
| 维度   | 本案        | 类案    | 对判断的影响     |
| ---- | --------- | ----- | ---------- |
| 定价   | 要约价、溢价、估值 | 对应指标  | 本案是否明显更贵   |
| 标的状态 | 盈利、增长、杠杆  | 盈亏及周期 | 是否属于困境私有化  |
| 交易结构 | 资金来源、持股   | 同类结构  | 完成风险和母公司压力 |
行业估值必须说明样本口径，不能把“全部港股券商中位数”和“头部中资券商平均值”混用。
四、美国 SEC Tab
页面定位
美国 Tab 的基本单位应是“商业事件”，不是“SEC filing”。
同一交易涉及的：
* 8-K
* Exhibit 2.1
* Exhibit 10.1
* 425
* S-4
* DEFM14A
* 新闻稿及投资者演示
应尽量合并到同一事件中。
424B、FWP和结构性票据可以保留为独立“资本市场流水”，不要与重大并购和战略融资混排。
并购事件首屏
需要明确：
* 交易价值、企业价值
* 现金还是股票
* 每股对价或换股比例
* 公告溢价
* 合并后股权比例
* 预期协同
* 是否增厚EPS/FCF
* 预计完成时间
* 股东和监管批准
* 最新市场反应
EQT收购Range的页面，用户应先看到约129亿美元隐含股权价值、0.987换股比例、约20.6%溢价及3.25亿美元基础年化协同，而不是先看到8-K Item编号。ir.eqt.com
SEC金额抽取注意事项
以下金额不能误认为交易规模：
* 面值
* 注册费
* 债券票面金额
* 单张票据价格
* 转换价格
* 最低报价规则金额
金额必须带语义：
* Equity value
* Enterprise value
* Purchase price
* Per-share consideration
* Termination fee
* Debt principal
* Financing commitment
* Offering size
管理层预测必须明确标注为前瞻性信息，例如：
* 协同目标
* 五年自由现金流
* EPS增厚
* 杠杆下降目标
* 成本节约路径
不要与历史财务事实混写。
类案与行业对比
类案至少满足：
* 同一细分行业
* 相同支付方式
* 类似资产组合
* 类似战略目标
* 相近监管复杂度
例如天然气并购，应比较：
* 产量与储量
* 核心盆地
* 钻井库存
* 盈亏平衡气价
* 中游资产
* 协同占交易价值比例
* 合并后杠杆
行业对比则补充：
* 商品价格周期
* LNG出口能力
* 电力和数据中心需求
* 行业资本开支纪律
* 近期整合趋势
EIA预计美国天然气产量在2026和2027年继续增长，意味着需求增长并不必然转化成价格上涨，供给弹性也应进入投资分析。U.S. Energy Information Administration (EIA)

六、给实施 agent 的验收标准
* 三个 Tab 的列表页和详情页使用同一研究型阅读逻辑。
* 页面不得出现 null、[]、undisclosed、analysis 等底层值。
* 不显示任何空模块。
* 30秒内可以识别事件、金额、阶段和主要商业意义。
* “最新变化”只使用实质性公告。
* 类案必须解释可比原因及对本案的启示。
* 新闻和行业报告必须保留来源链接及发布日期。
* 公告事实、外部信息和本站分析在模块层面区分。
* 全量事件可以先做“公告速览”；只有完成公开检索的事件才标记“公开资料深读”。
* 首批验收样本建议固定为：龙佰西澳矿砂、国泰君安国际私有化、EQT—Range合并。
