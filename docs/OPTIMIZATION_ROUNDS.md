# 事件研究改版：三轮实施

依据 David 原始 brief：EVENT_RESEARCH_REDESIGN.md 与 EVENT_RESEARCH_PAGE.md；保持三个市场共用研究阅读逻辑，不另建信息架构。

## Round 1 — 完成：治乱、对齐骨架

- **三个 Tab 从字段页转向事件研究页**：出海、港股、美股主入口直接进入本市场事件库；`#/events` 收敛到出海研究事件库。详情统一进入研究文章，旧参数也不再选择字段矩阵。
- **统一阅读骨架**：沿用标题、状态、摘要、核心数字、类案、行业、意义、观察项、时间线、来源；有内容才显示模块。二级主导航压缩为“总览｜事件库｜市场特色栏目｜方法”，旧文件视图及长链接放入“更多”。
- **后台结构化、前台内容化**：构建发布投影过滤 null、undisclosed、未披露、资料不足、未抽取、analysis、disclosed、[] 等展示占位值；保留机器 provenance/layer。源 state 与研究稿不改写；验证器检查发布数据展示字符串及可用浏览器的实际研究文章与卡片文本，命中即失败。
- **两种深度如实标记**：每次发布重新计算，不信任原 depth。公开资料深读须摘要至少300字，并有核心公告链接、至少两项时间线节点、有效类案、经营或财务数据、财务/战略/投资至少两个实质分析维度；其余为公告速览。此轮不补写港美研究正文。
- **统一工程发布**：一个缓存常量驱动初始 CSS/JS 与延迟事件、SEC 数据资源，版本为 `20261027d0`；展示名称统一“出海信披”。继续由 CI 构建忽略的 assets 数据产物，不将产物加入版本库。

## Round 2 — 计划：首屏、进展、资料包

- 按 brief 配置类型首屏数字槽位：出海突出权益、现金/设备/或有支付、地区与项目成熟度；港股私有化突出每股价、溢价、估值、持股、现金需求、融资、条件和时间；Chapter 14 突出百分比率、分类、股东批准、对价、盈利及估值；SEC 并购突出股权/企业价值、支付方式、每股对价或换股比、溢价、协同、完成时间及批准条件。
- 最新实质变化以改变交易事实、条件或完成概率的公告为准；Rule 22、例行月报和新增附件数量不得自动成为进展。首次披露、最新文件、最新实质变化分别维护并回溯原文。
- 事件资料包四层：核心文件（初始公告、协议、通函、完成/终止）、进展文件（补充、审批、表决）、企业资料（年报、中报、演示）、外部资料（新闻、研报、行业报告）。辅助交易披露默认折叠。
- 数字带语义与来源；管理层协同、EPS/FCF 预测标明前瞻性；公告与媒体金额口径冲突有具体解释。

## Round 3 — 计划：研究能力与验收

- 接入并保留新闻、财报、研报的来源与日期，形成事实更新后重写摘要的机制。
- 类案按交易动作、行业、控制结构、市场监管、规模及财务状态排序，解释相似、差异及对判断的影响；不硬凑数量。
- 行业模板注明样本、日期、口径；财务、战略、投资结论分别回答资金与报表影响、组织业务变化、定价与催化条件，并提供证据链接。

验收 checklist：

- [ ] 三市场列表与详情共用研究逻辑，无字段矩阵默认路径。
- [ ] 30秒识别事件、规模、阶段、商业意义；无空模块及禁用占位值。
- [ ] 首次披露、最新实质进展、关键数字均可回溯原文，程序性文件不挤占主体。
- [ ] 深读满足真实内容门槛；重点样本有2—3个真正可比案例并解释差异。
- [ ] 行业数据注明样本、日期、口径；公告事实、财务数据、新闻观点、本站分析清楚区分。
- [ ] 龙佰西澳矿砂、国泰君安国际私有化、EQT—Range 固定样本人工验收。
- [ ] 构建、validate、Python 测试、Node 渲染测试通过；移动端无溢出，来源可访问。
