# 事件研究改版：三轮实施

依据 David 原始 brief：EVENT_RESEARCH_REDESIGN.md 与 EVENT_RESEARCH_PAGE.md；保持三个市场共用研究阅读逻辑，不另建信息架构。

## Round 1 — 完成：治乱、对齐骨架

- **三个 Tab 从字段页转向事件研究页**：出海、港股、美股主入口直接进入本市场事件库；`#/events` 收敛到出海研究事件库。详情统一进入研究文章，旧参数也不再选择字段矩阵。
- **统一阅读骨架**：沿用标题、状态、摘要、核心数字、类案、行业、意义、观察项、时间线、来源；有内容才显示模块。二级主导航压缩为“总览｜事件库｜市场特色栏目｜方法”，旧文件视图及长链接放入“更多”。
- **后台结构化、前台内容化**：构建发布投影过滤 null、undisclosed、未披露、资料不足、未抽取、analysis、disclosed、[] 等展示占位值；保留机器 provenance/layer。源 state 与研究稿不改写；验证器检查发布数据展示字符串及可用浏览器的实际研究文章与卡片文本，命中即失败。
- **两种深度如实标记**：每次发布重新计算，不信任原 depth。公开资料深读须摘要至少300字，并有核心公告链接、至少两项时间线节点、有效类案、经营或财务数据、财务/战略/投资至少两个实质分析维度；其余为公告速览。此轮不补写港美研究正文。
- **统一工程发布**：一个缓存常量驱动初始 CSS/JS 与延迟事件、SEC 数据资源，版本为 `20261027d0`；展示名称统一“出海信披”。继续由 CI 构建忽略的 assets 数据产物，不将产物加入版本库。

## Round 2 — 完成：首屏、进展、资料包

- **一 统一原则**：发布投影新增 `metric_slots`、首次披露 / 最新文件 / 最新实质变化及四层 `source_layers`；有值才显示，不补造事实，不改研究正文。三市场共用 `is_substantive`，在覆盖稿应用后统一计算；Rule 22、例行425、月报、翌日披露、寄发通函、会议日期/会议通知及附件型文件不占实质变化。
- **二 出海**：买方、卖方、标的、国家地区、交易形式、权益比例、对价及支付、阶段按已有结构字段与带来源数字投影；已有项目成熟度在首屏显示，保留许可、PFS/BFS、FID、投产和资源产能信息。出海 overlay JSON 原样保留。
- **三 港股**：私有化、Chapter 14、关连/CCT、配售供股、监管执法各用自己的槽位；值为空即隐藏。资料包分核心文件、进展文件、企业资料、外部资料，Rule 22 / 辅助交易披露默认折叠。
- **四 SEC**：并购按企业价值、股权价值、对价形式、溢价、每股对价/换股比、协同、预计完成、批准条件投影；数字保留原语义和来源，协同/EPS/FCF 标记“前瞻”。不改写已有港美研究正文，也不生成新闻金额差异解释。
- 缓存只由 `window.PUBX_BUILD` 驱动；补充 Python 结构测试与 Node 渲染测试，覆盖类型槽位、空值隐藏、统一程序文件过滤、日期区分、来源分层及默认折叠。构建数据产物不提交。 验证结果：完整 build_site、48 项 Python 测试及全量 3,973 事件 Node 渲染通过；validate 为 0 errors，浏览器 26 路由、150 链接和三种宽度通过（存量批次命名 WARN；无 raw 缓存的原文子串核对 SKIP）。

## Round 3 — 完成：最终结构与发布验收

- **类案与行业始终分区**：发布投影及前端都只展示带真实启示的有效类案，明确标注“对本案意味着什么”；比较说明不能独立撑起空类案模块，不补写启示、不硬凑三个。行业行必须同时具备正文、样本、日期及口径，否则隐藏。
- **金额解释靠近核心数字**：优先显示既有 `cash_explanation`；缺少该字段时，仅将明确涉及公告与媒体金额口径差异的既有观察项原文提升至核心数字下方，保留来源引用，不推导或生成冲突。
- **分析问题提示**：有正文的财务、战略、投资维度分别提示“花多少钱、钱从哪来、报表影响”“解决什么问题、业务/组织怎么变”“价格是否合理、完成概率与催化”。空维度整块隐藏。
- **轻量覆盖统计**：仅在现有各市场总览显示公开资料深读与公告速览数量。单一缓存常量更新为 `20261027d3`。
- **范围**：仅修改展示、发布投影、测试及实施记录；所有研究 JSON 原文保持不变。新闻、财报、研报来源和日期沿用已有资料包；本轮没有接入新来源、构建摘要重写机制或新增类案排序算法。
- **验证**：完整 build_site、50 项 Python 测试（scripts 38 + pipeline 12）、全量 3,973 事件 Node 渲染及三个固定样本均通过。validate：0 errors / 1 warning / 2 skips；warning 为存量批次旧命名，skips 为缺少 raw 原文缓存与环境禁止本地 HTTP socket，未宣称完成浏览器/移动端或实时来源可访问性验收。构建产物及生成的 state 变动不提交。
