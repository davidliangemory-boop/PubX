## 运作类型（`assets/page_ia.js` HK_TYPES / US_TYPES，顺序＝优先级，命中第一个）
港股：收购与私有化（收购守则/私有化 或 标题含要約/協議安排）→ 并购与重大资产交易（主要/非常重大/须予披露/并购）→ 关连交易 → 持续关连交易（CCT）→ 配售/供股/股权融资 → 控制权与治理（治理变更）→ 监管执法 → 停复牌/清盘/其他公司行动。

SEC：并购与业务合并（event_type 并购 或 425/S-4/F-4/DEFM14A/SC TO/14D9/13E3，或 Item 2.01/5.01）→ 重大协议签订/终止（1.01/1.02）→ 结构化票据/债券定价（资本市场流 424B2/FWP）→ 股权与注册发行（融资、2.03、3.02、S-1/F-1/S-3/424B）→ 股东表决与证券权利（5.07/3.03）→ 上市地位与审计（3.01/4.01）→ 董事高管与章程（治理变更、5.02/5.03）→ 业绩/Reg FD（2.02/7.01）→ 外国私人发行人 6-K 其他 → 其他重大事项。
