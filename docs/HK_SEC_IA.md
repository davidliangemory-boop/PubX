### 港股（族 · 桶 · 规则）
- **交易与融资**：收购与私有化（收购守则/私有化 或 标题 收購守則/要約/私有化/協議安排）→ 并购与重大资产交易（event_type 主要/非常重大/须予披露/并购；或 *兜底类* 标题含 須予披露交易/主要交易/非常重大交易）→ 关连交易 → 持续关连交易（CCT）→ 配售/供股/股权融资（*兜底类* 标题含 供股/配售/認購新股/代價股份/可換股債券/根據一般或特別授權發行）→ 清盘/债务重组（清盤/債務重組/重組計劃/臨時清盤人）→ 股本重组/回购/股份变动（股本重組/股份合併/拆細/每手買賣單位/購回/回購/翌日披露報表/法定股本）
- **上市地位与监管**：监管执法（含 *兜底类* 标题 紀律行動/譴責）→ 停复牌与复牌指引（停牌/復牌/暫停買賣/取消上市）
- **治理与股东事务**：股息与分派 → 治理·董事/高管/核数师变动（董事/行政總裁/主席/公司秘書/授權代表/核數師/委員會/辭任/委任）→ 治理·股东大会/通函/章程 → 控制权与治理·其他（event_type 治理变更但标题无上述线索）
- **经营与信息披露**：业绩/经营数据/盈利预告 → 海外监管公告（A/H 同步）→ 基金/结构性产品文件（基金說明書/產品資料概要/發行章程）→ 业务进展/自愿公告（标题线索）→ 内幕消息（未细分）→ 英文版公告（中文未发布）→ 其他公司行动
- *兜底类*＝event_type 为 治理变更 / 其他重大事项：只有这些事件才按标题改道进交易类桶，已有 event_type 的事件不动。

### SEC
- **交易与融资（8-K/注册）**：并购与业务合并 → 重大协议签订/终止 → 股权与注册发行 → 股东表决与证券权利
- **资本市场流水（424B2/FWP，仍是独立 stream）**：结构化票据·初步定价（preliminary/not complete/Subject to Completion + 结构化线索）→ 结构化票据·最终定价（结构化线索：Structured Investments/Linked to/Underlier/Auto-Callable/Buffer/Barrier/Contingent/Digital/Trigger/Basket/Product·Index·Underlying·Market Measure Supplement 等）→ 固定/浮动利率债券（Fixed/Floating Rate、Senior/Medium-Term/Subordinated Notes、Debentures）→ 初步定价补充（品种未识别）→ 最终定价补充（品种未识别）。424B3/5 等仍归「股权与注册发行」。
- **治理、业绩与其他（8-K）**：上市地位与审计 → 董事高管与章程 → 业绩/Reg FD → 其他重大事项
- **外国私人发行人 6-K（标题/摘录线索）**：业绩与经营数据 → 股东大会与表决 → 股本变动/回购/拆并股 → 融资与发行 → 股息与分派 → 董事高管变动 → 交易与协议（标题线索）→ 上市地位/退市 → 研发/临床/资源勘探 → 其他（仅封面/无标题线索：摘录只有 Form 6-K 封面样板）
